# 教師・保護者向けの手引き

このゲームは、同梱の改訂教材PDFをもとにしています。主イエス様のお名前による祈り、真の神への信仰、従順、悔い改め、ゆるし、敵への愛を保っています。プレイヤーが聖書の歴史や結末を変える分岐はありません。

## 学習目標

1. ヨナが神様の命令から逃げたために、神様の罰を受けたことを知る。
2. 神様が正しいとされることを行う。
3. 友だちのまちがいをゆるす。

聖句：「あなたの敵を愛しなさい」（マタイによる福音書5:44）。
原教材の6つの本文見出しを、各章の読書画面上部に表示します。学習目標は教師ガイド、祈りと聖句は冒頭に収録しています。もくじから章を選んだ場合は、冒頭の祈りを飛ばします。表紙の「お祈りを読む」からも確認できます。

## 問いかけ

名前を唱える・海の味を答える・絵でヨナを指す等の活動は、声に出して行えます。選択肢には得点、制限時間、失敗による罰はありません。最後の「ゆるすのがむずかしい」も、気持ちを認め、神に助けを求める応答につながります。

## 聖書の事実と教材表現

- 魚の切り抜き構図・明かり・服装等は挿絵上の表現で、聖書の記述として断定しません。画像の元ファイル名に Whale とありますが、画面と本文では「大きな魚」としています。
- ヨナが逃げた理由の詳しい憶測、魚の内部の断定、浜辺での創作のせりふは加えていません。
- ニネベが偶像をすべて壊した、永久に善良な町となった、その後二度と攻撃しなかった、等の聖書本文にない断定は加えていません。
- ヨナ書4章の展開は、参照PDFの物語範囲を越えるため加えていません。
- あらしはこの物語の出来事であり、すべての災難が本人の罪への罰だという一般則として扱いません。
- 断食や家畜への命令は当時の出来事の説明です。児童への実行課題ではありません。
- 最後のふり返りでの応答は学習のための補助文で、ヨナの発言や聖書の直接引用ではありません。
